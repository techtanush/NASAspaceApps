# Platform implementation decisions

- The authoritative base is `825d204b3e8cee8ade01db40ca8fb4020d0ec943`. All changes stay on `tanush/platform-agents-integration`. No other contributor's implementation is copied into this branch.
- The frozen kit is byte-identical, except its expressly editable `extra-tanush` dependency list. Missing science and renderer entry points fail by name. Production never loads test doubles.
- Mission contract bytes are immutable. Acceptance is a separate, append-only `mission_acceptances` record. The API overlays its accepted timestamp when returning the immutable contract. This resolves the conflict between an immutable contract and a later acceptance timestamp without rewriting scientific content.
- Verification tests and results remain immutable. Later diagnosis and planning decisions are separate persisted records and runtime references, rather than retroactive changes to test inputs.
- Replans remain bounded by the catalog, with at most three attempts per candidate. The guide's contradictory phrasing about a fourth attempt is interpreted conservatively: no fourth attempt is permitted.
- Docker was unavailable locally. Checks use the documented native PostgreSQL fallback: a private PostgreSQL17 cluster with PostGIS3.7 on loopback port5433. Application and final-test databases use UTF8 and template0. Earlier SQL_ASCII databases are retained; no unrelated database is dropped.
- Preflight always probes the production entry points. Consequently standalone synthetic preflight on this platform-only branch reports missing collaborator components. It does not substitute doubles to make the command green. Offline platform integration tests explicitly inject the frozen-port doubles; the merge must rerun those tests against the actual components.
- `CHANGE-REQUEST-001.json` records an unavoidable contradiction between the frozen JSON export schema and architecture35's required export object, plus omitted error response declarations. The implementation follows the required JSON object. The feature kit remains frozen. Central checkpoint `4c9897c96dc082b82b654988ff6898f85b90e504` resolves the schema contradiction; final strict C3 transport and affected checks pass in preview `ceda96f049607abc33a453966fa367fb9f5541bd`. Readiness is scoped to integration with that checkpoint, rather than the old C2 contract.
- Artifact downloads implement the frozen whole-object200 `application/octet-stream` contract, including digest headers. Range requests receive the complete object with `Accept-Ranges: none`; no undeclared206/416 branch is advertised.
- Real OpenAI credentials, real NASA data decoding and physical validation are separate gates. Tests with fake HTTP providers or scientific doubles demonstrate orchestration and policy only; they do not establish real data or physical scientific validation.

- Final source is `eb4cd4c63e4477a050370c8084c89c596e9ea1af`. The completed full platform suite passes278 tests without skips; the separate kit passes20. Aggregate `make check` stops at the required missing-real-component preflight; remaining checks are executed separately and recorded.
- Unexpected scientific child exceptions transport only their type. Three actual spawned-child regressions demonstrate empty stderr and absence of token-bearing error text; cancellation acknowledgement and child teardown have separate2s/5s bounds.
