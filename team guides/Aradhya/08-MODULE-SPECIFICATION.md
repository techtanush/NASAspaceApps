# Aradhya — module specification

File-by-file contract for the frontend and the pure passport renderer. Types come from the kit (`contracts/openapi.bundled.json`, `contracts/ui-testids.json`, `analogforge.ports.passport_renderer`, `science_payloads` artifact types); behaviors come from architecture 16–19, 35, 39, 40. Where this file is more specific, it wins for your branch. You compute **no** scientific value anywhere; you display persisted server data and the artifacts listed in architecture 35 §5b.

## 1. Global rules

* Stack: React 19, TypeScript (strict), Vite, React Router, TanStack Query, MapLibre GL JS, native accessible HTML/CSS, `lucide-react` icons, Vitest + Testing Library, Playwright, `msw` (mock mode only), `ajv` (2020-12) for fixture/spec validation, `@axe-core/playwright`, `openapi-typescript`. Node 22, pnpm 10 (lockfile committed).
* **One OpenAPI:** generate `apps/web/src/generated/schema.d.ts` from `../../contracts/openapi.bundled.json` with `openapi-typescript`; never hand-edit; `pnpm run generate:client` + `git diff --exit-code` must be clean (UIX-02). No scientific enum is redeclared by hand — import `components["schemas"]["QualificationStatus"]` etc.
* **Server-owned truth:** statuses, selection pointers (`selected_candidate_id`, `selected_portfolio_id`), revisions, cursors and allowed actions come from responses. No optimistic scientific updates. Null measurements render the text `Unknown` inside `data-testid="unknown-value"`, never `0`, `NaN`, `-` alone or blank.
* **Test ids:** implement **every** id in `contracts/ui-testids.json` with its required `data-*` attributes. A Vitest test loads the JSON and fails if an id does not occur in `apps/web/src`; a Playwright journey asserts each id where it should appear (UIX-04).
* **No external requests:** the app loads no CDN fonts/scripts/tiles; the default basemap is bundled/offline; all network goes to `VITE_API_BASE_URL` (default `/api/v1`).
* **Mock mode:** `VITE_API_MOCK=1` starts MSW with a permanent top banner `MOCK PREVIEW — not a real backend` (`data-testid="mock-banner"`, not in the kit list because it never exists in real mode). `vite build` **fails** if `NODE_ENV=production` and `VITE_API_MOCK=1` (a Vite plugin throws). Real mode never imports `msw`.
* **Accessibility:** semantic landmarks, skip link, visible focus, labelled controls, text+icon status (never color-only), live region for stage changes/terminal results, reduced-motion disables playback autoplay, tables/cards alternative for every chart and map, 360 px single column, 200 % zoom reachable.
* **Security:** render server/model strings as text only; no `dangerouslySetInnerHTML`; links only `http(s)` from trusted metadata; no secrets in `VITE_*`.

## 3. API layer

* `client.ts`: typed fetch wrapper; base URL; JSON; `Idempotency-Key` header (one UUID per logical user action, **reused verbatim on transport retry**); `expected_revision` supplied by the caller from the current snapshot; structured `ApiError` (`code,message,request_id,retryable,details`); `X-CSRF-Token` only when a session response supplies one; abort support.
* `queryKeys.ts`: every key starts with `['workspace', workspaceId, …]`; filters normalized deterministically.
* **Mutation protocol** (architecture 17 §4): validate locally → one key → submit → on 202 invalidate snapshot and affected lists → on uncertain network outcome refetch the snapshot first, retry with the *same* key → on 409 `REVISION_CONFLICT` refetch and show what changed (never auto-repeat a stale semantic action) → on 422 preserve user input and show field errors. Optimistic updates only for local view preferences and draft text with visible unsaved state.
* `runStream.ts`: **one** stream controller per mounted run shell. Authenticated `fetch` stream with a tested SSE parser (`id:`, `event:`, `data:`, comments); cursor = `snapshot.last_event_seq`; dedupe by `run_id+seq`; gap (`seq != last+1`) ⇒ refetch snapshot and reopen; `410 EVENT_CURSOR_EXPIRED` ⇒ snapshot resync; reconnect backoff 1, 2, 4, 8, 15 s with jitter; heartbeat comments are health only; terminal event ⇒ final snapshot, deliberate close, no reconnect; unmount/run switch clears timers and aborts; hidden tab pauses playback and reduces polling. After any reconnect refetch the snapshot.
* `artifacts.ts`: `useEvidence(id)` → `GET /evidence/{id}`; `useArtifactJson<T>(sha)`; `findEvidenceByAlgorithm(ids, key)` where the algorithm ids are imported from the kit file `contracts/algorithm-ids.json` (single source; never retyped). Artifact JSON is parsed into the types of architecture 35 §5b and displayed exactly as received.

## 5. Maps

* `EarthMap.tsx`: one MapLibre instance per mounted map; neutral style from `public/basemap` (land polygons or a graticule fallback; **no network**); layers from `DisplayLayerManifest` (`EARTH_WEBMERCATOR_IMAGE` with four `earth_corners` NW,NE,SE,SW); candidate extents/routes/waypoints as GeoJSON (WGS84 lon,lat); stable feature ids; React owns selection and layer toggles, MapLibre owns viewport; cleanup on unmount; layer registry (`layerRegistry.ts`) refuses a layer whose manifest body ≠ EARTH or lacks corners; switching candidates removes the previous candidate's layers first. WebGL failure ⇒ catch, render the list/table fallback.
* `PlanetaryPanel.tsx`: canvas/SVG viewport; `affine.ts` implements screen→viewport→pixel→world and back with the GDAL-order coefficients; tests on all four corners + one interior point (≤ 0.5 px); rectangle draw + numeric bbox entry (same `AreaOfInterest`); refuses Earth CRS metadata; masked pixels transparent/hatched; zoom never changes values or removes scale warnings.
* Route styles: proposed dashed, current solid, prior muted, violated segments strong pattern + label, forbidden hatched.

## 6. Mock backend (mock mode; development and Playwright `--mock` runs)

A stateful in-memory MSW server implements every endpoint the UI calls (all 43 operations; unsupported ones return a documented 501 `error-panel`). It is **a faithful scripted replay of the practice storylines** (architecture 40) and obeys the same rules as the real API (idempotency, `expected_revision` 409, workspace id, error envelope, SSE with `after`, 410 on a stale cursor, 202 `Retry-After` for exports). Requirements:

* Fixtures live in `src/mock/fixtures` and are **validated against the bundled OpenAPI by Vitest (UIX-03)**; they use the kit's mission/rover fixtures byte-for-byte and `catalog` ids.
* Scripts under `src/mock/scripts/`: `marsMobility` (S-RASTER-1: 6 candidates + 2 excluded windows, the truth table of architecture 40 §5, the seeded `SCALE_MISMATCH` critic issue OPEN→RESOLVED with matrix revision 2, attempts 1 FAIL/ROUTE, 2 FAIL/ANALOG, 3 PASS on `Practice grid-r0c0`, passport LIMITED), `graphRegression` (S-GRAPH-1), `moonSiteOnly` (S-MOON-SITE-ONLY), `roverLite`, `noEnergy`, `smallBattery`, `searchLimit`, `liveUnbound` (`live-hackathon-v1` with `allowed_modes: []`), `liveNoKey` (POST `/runs` live ⇒ 503 `PROVIDER_AUTH_FAILED` with `details.dependency`). The script is chosen by scenario id + rover name.
* Events advance on a fast timer (200 ms) and are replayable from any cursor; killing the (simulated) connection with `page.context().setOffline(true)` must produce the paused→resync path; `?mockSpeed=` query slows/speeds it.
* **Mock exports are real:** `scripts/build_mock_exports.py` builds a `PassportExportBundle` from the fixture data, calls the **real** Python renderer for html/json/csv, and writes the bytes + digests into `src/mock/exports/` (committed). The mock export endpoints serve those bytes, so the journey's digest checks exercise the real renderer.
* The mock never fabricates scientific values by computing them; it replays fixture values that were authored to satisfy architecture 40.

## 7. Passport renderer (`rendering/passport/`)

`create_passport_renderer()` returns an object implementing `PassportRenderer` with `renderer_version = "1.0.0"`.

* **Pure:** imports only stdlib, `jinja2`, `markupsafe`, `pydantic` and kit modules; no network/DB/model/clock/env; subprocess import test proves it (UIX-09). Deterministic: same bundle+assets+format ⇒ identical bytes; the only time printed is `bundle.generated_at`.
* **Validation:** a non-draft bundle must satisfy the `PassportExportBundle` validators; additionally raise `RendererError` for: unresolved references (a `qualification.candidate_id` not in `candidates`, an attempt candidate missing, `passport.evidence_ids` ids absent from `evidence_appendix` **unless** the id is the assurance evidence), `assurance.publication == "BLOCKED"`, manifest digest mismatch (`sha256(canonical_manifest_json.encode()) != manifest_sha256`), a qualification row for a requirement not in the mission, an `AttemptRecord.result.outcome` inconsistent with `failure_category`. Codes: `UNRESOLVED_REFERENCE`, `BLOCKED_AUDIT`, `MANIFEST_DIGEST_MISMATCH`, `REQUIREMENT_UNKNOWN`, `INCONSISTENT_ATTEMPT`. Drafts render with a conspicuous `DRAFT — INCOMPLETE` banner and never raise for missing assurance.
* **HTML** (self-contained, UTF-8, inline CSS incl. print CSS, no JavaScript, no external URL loads, Jinja2 autoescape, `markupsafe.escape` on every dynamic string): sections with ids `cover`, `mission-contract`, `target-and-sites`, `qualification`, `compatibility`, `prove-it`, `portfolio`, `critic-limitations`, `assurance`, `next-steps`, `provenance`. Cover headline logic: (1) some attempt `PASS` and assurance ≠ BLOCKED ⇒ **"Qualified for these tests under these assumptions:"** + `passport.qualified_uses`; (2) else `not_run_reason` ⇒ its text; (3) else attempts exist and none PASS ⇒ **"No supported recommendation under the accepted contract"** + latest outcome (FAIL/INCONCLUSIVE); (4) else **"Not verified"**. Always: mode badge text (`LIVE`/`REPLAY`/`SYNTHETIC` + replay source), "Modeled terrain-feasibility verification — not physical rover execution", `manifest_sha256`, assurance publication + each audited claim's `permitted_statement`, **every** requirement row (status text, stage, evidence ids, limitations), **every** attempt in order with parent, strategy, changed elements, outcome, category, benchmark rows, violations, diagnosis text, a separate GAP list and UNKNOWN list, scale/support next to every quantity, null as `Unknown`, embedded `ProvidedAsset` images as `data:` URIs (png/svg), and a provenance appendix (source locks, evidence ids, hashes). Print CSS: light background, repeated table headers, `page-break-inside: avoid` on rows/cards, visible ids.
* **JSON:** object of architecture 35 §4 (`export_schema_version`, `manifest_sha256`, `canonical_manifest` parsed from `canonical_manifest_json`, `bundle` = every bundle field except `canonical_manifest_json` and assets), `sort_keys`, 2-space indent, trailing newline, nulls preserved, `ensure_ascii=False`.
* **CSV:** exactly `CSV_COLUMNS` in order; one row per (bundle candidate × mission requirement); `qualification_status` from the row (`PENDING` if absent), `evaluation_stage` from the row's explanation-independent field when present else empty; `target_value` / `earth_value` found in `evidence_appendix` by the row's evidence ids using this metric mapping: `slope_band_area_fraction` → `slope_area_fraction:<lo>-<hi>` (earth from the candidate evidence, target from the target profile's same metric), `slope_distribution_w1_deg` → `slope_w1_deg`, `unique_slope_exposure_m` → `unique_exposure_m:<requirement_id>`, `completed_task_count` → `tasks_completed`, `final_battery_reserve_pct` → `reserve_pct`, `surface_temperature_min_k` → `min_temperature_k`; empty (never `0`) when absent; multi-valued cells joined by ` | `; CSV-quoted; any text cell beginning with `=`, `+`, `-`, `@`, tab or CR gets a leading `'`; `verification_outcome` = outcome of the candidate's highest `attempt_number`; `assurance_disposition` from the audited claim with that requirement id and candidate id; `manifest_sha256` on every row; UTF-8, `\n` newlines, header row.
* **Filenames:** `analogforge-passport-<mode>-<first8(passport.id)>-<first8(manifest_sha256)>.<html|json|csv>`; media types per the kit; `sha256` = SHA-256 of `content`; `referenced_evidence_ids` = every evidence id printed.
* **Fixtures** (`tests/unit/passport_renderer/fixtures/bundles/`): positive, supported-negative (ALLOWED), limited (UNKNOWN/no-rover), failed-with-replan (3 attempts, S-RASTER-1 values), inconclusive (search limit), composite, hostile-strings (`<script>`, `=cmd|…`, quotes, newlines, RTL, 10 kB string), replay (with `replay_source_run_id`), draft. All are **valid kit bundles built in code** by a helper and checked by `tests/contracts/ui/test_bundle_fixtures.py`.
