# Aradhya handoff checklist

Use the common handoff template under `team handoffs/aradhya/<checkpoint>/`. U0 is an early functional interface; U1 is full experience/renderer/test completion. Avoid a single unreviewable end-of-event dump.

- [ ] Correct branch/worktree/profile and base/main/schema hash recorded.
- [ ] Only owned frontend/client/renderer/browser-test/package paths changed.
- [ ] Generated API client is current and its scientific enums are not duplicated.
- [ ] Visible mock preview is separate from actual API mode; no silent response fallback.
- [ ] Authoring/autosave/preparation/acceptance/import/no-rover flows work with clear errors.
- [ ] Qualification/evidence/critic/compatibility/test/portfolio/passport screens preserve all statuses and limitations.
- [ ] Scientific results are server-owned; reload/event-gap/cursor-expiry/reconnect/terminal close tested.
- [ ] Earth versus planetary CRS and provided display manifests respected; WebGL fallback works.
- [ ] Fail/replan/pass history reflects actual persisted attempts and fixed input hashes.
- [ ] HTML/JSON/CSV renderer is pure, escaped, printable and preserves correct byte/manifest digests.
- [ ] Desktop/tablet/mobile, keyboard/status labels and actual browser suites pass or exact limits reported.
- [ ] Real backend/science integration is proved independently of mock-preview tests.
- [ ] Frontend dependencies/asset licenses are locked/documented; Python dependency requests routed to Tanush.
- [ ] No secret/internal path/provider reasoning or fake NASA claim leaks through UI/export.
- [ ] Exact SHA, commands/results, seed/profile details, required backend gaps and external blockers included.

The integrator should be able to run your interface and renderer from a clean checkout, identify their actual mode, reproduce tests and connect to the accepted backend without reverse engineering hidden local settings.
