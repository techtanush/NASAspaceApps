## Integration boundaries

Real-backend initialization was attempted against a new private local database and stopped because the installed PostgreSQL 17 lacks PostGIS. No real-backend, live-dataset or merged release gate is claimed. The private database has been stopped. Local preview runs the explicitly labelled mock backend at `http://127.0.0.1:5300`.

Tanush's optional visual data remains a separate delivery. Bundled Mars/Moon textures remain labelled placeholders; synthetic practice layers are not terrain at the named planetary target. Missing native resolution/height-reference information is shown as unknown or referred to source receipts. No scientific qualification, data lock, hash or measurement is generated by this UI.

The planning-v1 globe schema contains a nullable `relief_path` combined with `not.pattern`, which rejects null under JSON Schema. The frontend keeps an owned schema copy and restricts that negated pattern to strings, preserving the documented null option. The shared frozen contract was not edited. No imagery was imported from Aleph; the research sources are in the separate local research report.

Production C19 now explicitly classifies seven exact inert URLs from the pinned library bundles (license/documentation/sentinel literals). It continues rejecting external resource URLs. The new browser test independently verifies no external requests in the tested flow. No thresholds were reduced.
