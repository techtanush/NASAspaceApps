Gale Crater and Flagstaff

Which areas near Flagstaff have terrain most like our Gale Crater target? We screened four candidate areas using NASA elevation data and found two worth a closer look.

Two of four areas met the terrain threshold

We compared how common different slopes were across the Mars target and each Earth area. A smaller difference means a closer match on this measure.

How we used NASA data

Mars Orbiter Laser Altimeter (MOLA) provided elevations for the Gale Crater target. NASADEM provided Earth elevations for the four candidate areas. We derived slope distributions at the same comparison scale and used Wasserstein-1 distance to score the difference.

What the result supports

Areas A and B are candidates for further scouting. This regional run assessed terrain only. It did not assess rover performance, access, or field safety.

The public app offers a separate, labeled practice run where you can plan rover tests and open a modeled field brief.
